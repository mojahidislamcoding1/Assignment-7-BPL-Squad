# 🏏 Cricket Team Selector (Ultimate Dream 11)

A dynamic React web application designed for cricket enthusiasts to assemble and manage their custom Dream 11 cricket team. Users can claim free credits, view available players, and select their favorite squad members while adhering to team budget and selection constraints.

---

## 🛠️ Technologies Used

* **Frontend Library:** React.js
* **Styling & UI:** Tailwind CSS, DaisyUI (or Custom CSS)
* **Icons & Notifications:** React Icons / React Toastify (or SweetAlert2)
* **Package Manager:** npm / yarn

---

## 🚀 Key Features

1. **Free Credit Claiming System**
   * Users can claim free coins/credits with a single click to build their budget for buying players.

2. **Smart Player Selection Limit (Max 6 Players)**
   * Prevents adding more than 6 players to the selected list with real-time feedback and toast notifications.

3. **Dynamic Squad & Budget Management**
   * Real-time calculation of remaining coins, instant player removal options, and quick tab switching back to the player market for uninterrupted team building.

## 💻 Getting Started

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd your-repo-name
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```
